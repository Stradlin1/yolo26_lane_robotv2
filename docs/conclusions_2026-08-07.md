# Lane1 残差方案设计结论（2026-08-07）

## 1. 问题与诊断

**现象**：lane1（lead_lane）预测线质量差（抖动、穿线），视觉特征弱，
不依赖色彩空间，主要依赖 lane0 的语义位置。

**诊断结论（基于新数据集 0806 标签统计）**：

- lane1 是几何派生的短直线段：y 范围约 0.64~0.82（画面中段），
  直线拟合 MAE 中位 0.0085，验证了"两点连线"生成规则；
- lane1 相对 lane0 的偏移 Δ 集中在 -0.16~-0.03（约 -70~-13px @448），
  且与上一帧 lane1 有关（递归中点生成）；
- 旧标注混入：部分 lane1 是旧语义（锥桶下左侧边缘的小团点），
  与 lane0 关系弱，污染训练。

**结论**：lane1 不应作为独立视觉目标用"全图 320 类分类器"学习，
而应建模为 lane0 的派生线（lane0 + Δ）。

## 2. 数据集处理（已完成，直接改写远程标签，无备份）

对 `/root/ds0806/datasets` 的 train/valid 标签执行了三轮清理：

1. **直线性筛选**：lane1 点数 >= 3，且一条直线（或两段直线）拟合
   MAE <= 0.015，否则删除该 lane1 行；
2. **跨度筛选**：lane1 的 y 跨度 >= 0.04 且 x 跨度 >= 0.04，
   删除"锥桶底下小团"式标注（删 1107 条）；
3. **删除无 lane0 的 lane1**（119 条），符合"lane1 是 lane0 派生线"语义。

清理结果：

- train 含 lane1 文件：1992；valid：223；
- 单 lane1（无 lane0）样本：0；
- 保留的 lane1 均为"有 lane0、直线、跨度足够"的样本。

## 3. 模型结构方案：lane0 主干 + lane1 高斯先验残差分支

保持 ONNX 输出契约不变（`[1, 322, 56, 4]`：cls 全图 320 类 + offset）。

```
z ──> cls_heads.0 ──> soft-argmax ──> lane0_x_pred  [B, R, 1]   ← lane0 主干
z ──> cls_heads.1(z) + prior(lane0_x_pred) ──> lane1 logits     ← lane1 残差分支
```

### 先验形式：高斯先验

- 中心：`lane0_x_pred + δ`，其中 δ 为可学习偏移（对应 Δ 的期望，初值约 -32 格）；
- 宽度：σ 可学习（初始覆盖 Δ 的主要分布，约 15~20 格）；
- 实现：向 lane1 的 logits 添加高斯形状偏置（softmax 前加 log 域先验）。

### 决策点（已确认）

1. 先验中心使用**模型自身预测的 lane0**（不用 GT teacher forcing），
   保证训练/推理口径一致；
2. 先验形式选**高斯**，不引入可学习 MLP bias（少即是多，不够再升级）；
3. 先验初始强度要小（bias 幅度从 0 或小值起步），让模型逐步信任侧路，
   避免训练早期 lane0 未收敛时带偏 lane1；
4. 后处理（多项式平滑、帧间 EMA）先不做，先把模型内结构做对。

## 4. 明确不动的部分

- ONNX 输出契约：`[1, 322, 56, 4]`（cls 全图坐标 + offset）；
- 训练监督：lane1 目标仍为绝对坐标（dataset 不改）；
- 验证口径：仍比较绝对位置（val 不改）；
- 部署端解码：不需要改（lane1 输出仍是全图坐标语义）；
- lane0 / lane2 / lane3 分支：完全不动。
